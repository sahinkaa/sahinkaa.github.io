Tinge 26

Give your Home Screen badges a look that fits your icons. Tinge 26 can draw each badge’s background color from its app icon or use a static color you choose. Set the text color separately and choose an adaptive border, a border that matches the text or a custom border color. Set the border width to zero for a borderless badge.

The live preview shows four installed apps with badge counts of 1, 8, 64 and 128. Tap any preview icon to try a different app. Adjustments appear immediately in the preview. Changing the main Enabled switch requires a respring.

Based on Tinge by P2kDev.
